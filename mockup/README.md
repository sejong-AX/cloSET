# cloSET Interactive Web Mockup

웹 제작용 초상세 IA를 바탕으로 만든 단일 HTML 클릭형 목업입니다.

## 실행

`index.html`을 Chrome, Edge, Safari 또는 Firefox에서 더블클릭하면 됩니다. 외부 라이브러리와 인터넷 연결이 필요하지 않습니다.

## 구현된 화면

오늘의 착장, 내 옷장, Snap & Check, 케어 허브, Re:Using, 지출·탄소 인사이트, 설정 화면과 로그인·회원가입 목업이 포함되어 있습니다. 좌측 메뉴 또는 모바일 하단 메뉴로 전환할 수 있습니다.

## 구현된 상호작용

이메일 입력 검증, 로그인·회원가입 모드 전환, 비밀번호 표시, Google·Apple·Kakao 소셜 로그인 시뮬레이션, 샘플 계정 진입과 로그아웃을 조작할 수 있습니다. 앱 내부에서는 오늘의 착장 선택과 저장, 옷장 상태 필터와 검색, 신규 옷 등록 모달, 상품 샘플 불러오기와 STOP 판정, 세탁 시작·완료, 순환 경로 선택, 설정 토글, 알림 토스트를 조작할 수 있습니다.

## 편집

모든 CSS와 JavaScript가 `index.html`에 들어 있습니다. 색상은 파일 상단의 `:root` 토큰, 샘플 옷은 하단 JavaScript의 `items` 배열에서 변경할 수 있습니다.

이 파일은 디자인·흐름 검토용 목업이며 실제 서버, 로그인, AI 분석, 결제 또는 데이터베이스에는 연결되지 않습니다.
